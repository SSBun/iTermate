- [2026-11-06] 仅iTerm2：Bridge提供层级/操作/Shell与Pi状态，Codex原生被动监控；无独立TTY listener/Shell hook，不按标题/目录/进程名猜生命周期。PanelFollower仅前台+可见layer-0最大窗口+面板开关时显示；默认开，关闭不停止采集。App启动时iTerm2已运行才启Bridge，否则首次前台启动；刷新仅重启Bridge。已知Pi/Codex但status=nil为中性图标，不计状态；行ID区分nil/idle，unknown仅环境身份。FinishedSessionShortcut系统热键、AppSettings持久化，固定iTerm2路由；orderedSessionIDs按面板分组/Pin/Commands全顺序，折叠不排除。activateNextFinishedSession先mergingCodexObservations再applyingManualIdleStatuses；codexStatuses兼载校验身份的Codex状态（含null）和所有Agent有效手动idle，Pi问号覆盖后按idle排序。仅当次真实Session导航覆盖，不写生命周期/清Shell；新原始事件或身份变化释放覆盖，统计不受影响。每次重建候选，仅activityKind=agent，排除Shell、当前项、未知与模型推测。awaitingInput→finished（未读含失败）→idle→running，同级从面板顶部，不按当前项/完成时间。未知/关闭ID无候选，重复取首次；未入App快照的真实会话排末尾保留原生序。按真实Session ID记已访问；间隔<3秒继续，满3秒或全走完重循环。应用失焦在导航锁内清集合/时间，应用激活及内部切换不重置。finished确认转idle后只参加后续轮，关闭项移除；等待/idle目标不清完成，聚焦不清问号。Pi仅TERM_PROGRAM=iTerm.app且明确终端Session ID时启状态/发现/自动标题，其他终端继承ID不可信。子代理用subagents:rpc:v1:request status读取Fleet v1 totalActive，区分零/活动/未知；child-status仅促刷新，约2秒轮询。启动使零缓存失效，过期/失败不推完成；push/readonly共用派生，父/确认子代理活动running，明确等待优先，缺证据为空。hasRunningSubagents仅新鲜快照，分支动画支持减少动态效果。集成改变需Agents更新及Pi reload。Pi交互TUI confirm/select/input/editor明确等待，custom UI不默认提问。settled后台本地Ollama分类不阻塞hook；仅question等待，失败/超时/无效默认normal，不回退旧模型/启发式。分类中idle，空白不分类/计完成；非空正常settled且无未决活动可finished，aborted为interrupted不新增完成，error保留失败。全链10秒，新turn/分支/Session/退出取消；等待租约续报不调用模型，聚焦不清。Codex每2秒核实可见终端前台CLI；terminalWindowName完整UUID或29字符前缀，经现有daemon thread/loaded/list完整分页唯一扩展，再thread/read精确ID/根source/状态。loaded不等于running，空白会话不依赖rollout。无信号/零匹配/歧义/缺页/失败撤销绑定和overlay，不按cwd/时间/argv resume/旧FD猜，不缓存目录身份。异步落地复核Session、TTY、PID/启动时间、前台进程及前缀；切换取消，多终端认同ID拒绝自动绑定。已核实ID的根rollout仅可选状态/标题证据：首次尾1MiB，随后每轮8MiB，未追上不推状态。允许官方同用户socket符号链接，不启动daemon；手动绑定仅应急。Agents可复制[tui] terminal_title说明，不写配置，仅新开Codex生效，不用-c冒充共享服务。Codex完成确认仅Store展示，不写rollout/Bridge，绑定TTY/Session/进程/thread/完成ID时间；新轮或thread不复用，latestCompletion独立去重，中止不计成功。VenomDebugMonitor：唯一TTY普通running+真实前台进程树存活venom-cli debug build，父子关系追踪嵌套PTY；构建启动即识别，覆盖安装/重建/日志，不等日志子进程、不猜相邻TTY。每2秒，仅改图标，不改生命周期/优先级/统计；非debug或权限/TTY未知不显示。青绿7×7雷达，减少动态效果静止。菜单打开刷新，统计仅确认Agent Running及退出0完成。收藏经Bridge同动作动态path首个精确匹配激活；确认不存在才LocalWriteOnlyProfile指定目录建Tab/Window，actionResult决定关闭或报错。实现：ItermBridge.swift、FinishedSessionShortcut.swift、iTermateBridge.py、Pi集成、CodexSessionMonitor.swift、CodexAppServerClient.swift及docs/codex-monitoring.md。

- [2026-11-06] 仅iTerm2：Bridge提供层级/操作/Shell与Pi状态，Codex原生被动监控。无独立TTY listener/Shell hook，不按标题/目录/进程名猜生命周期。PanelFollower仅前台+可见layer-0最大窗口+面板开关时显示，默认开，关闭不停止采集。App启动时iTerm2已运行才启Bridge，否则首次前台启动，刷新仅重启Bridge。已知Pi/Codex但status=nil为中性图标，不计状态，行ID区分nil/idle，unknown仅环境身份。
- [2026-11-06] FinishedSessionShortcut系统热键、AppSettings持久化，固定iTerm2路由。orderedSessionIDs按面板分组/Pin/Commands全顺序，折叠不排除。activateNextFinishedSession先mergingCodexObservations再applyingManualIdleStatuses。codexStatuses兼载校验身份的Codex状态（含null）和所有Agent有效手动idle，Pi问号覆盖后按idle排序。仅当次真实Session导航覆盖，不写生命周期/清Shell。新原始事件或身份变化释放覆盖，统计不受影响。每次重建候选，仅activityKind=agent，排除Shell、当前项、未知与模型推测。未知/关闭ID无候选，重复顺序ID取首次，未入App快照的真实会话排末尾保留原生序。关闭项移除。等待/idle目标不清完成，聚焦不清问号。
- [2026-11-19] 用户要求 Ctrl+Tab 会话导航 MUST 优先跳到其他可跳转的问号会话。Bridge `activate_next_finished_session` 每次按有效状态重建候选，有其他 `awaitingInput` 时仅在等待组内按面板顺序选择未访问项，组内已访问完就重开一轮，因此已经访问过的问号仍优先于空闲。当前会话排除，手动覆盖成 idle 的会话按 idle 参与。无其他等待会话时沿用 finished（未读含失败）→idle→running 的访问轮次，同级从面板顶部排序，不按当前项位置或完成时间排序；无候选时不跳转。唯一问号处于焦点时使用此回退顺序；离开后若它仍是问号，下一次按键会再次将它列为优先候选，即使本轮已经访问。回归检查覆盖同一轮已访问的其他问号与 idle 并存、多个问号轮转、没有其他问号时的回退。已静态核对 Bridge 源码，真实 iTerm2 快捷键尚未实测。
- [2026-11-19] 用户要求仅 Ctrl+Tab 导航操作影响轮次，相邻快捷键请求间隔达到 2 秒时，下一次快捷键 MUST 重开一轮。Bridge 实例只在内存字段 `finished_navigation_last_press` 保存上次处理快捷键请求时的 `time.monotonic()` 时间点，初始为 `None`。在导航锁内用当前值减去上次时间点，系统时钟调整不影响间隔。没有后台倒计时；首次请求或间隔达到 2 秒时在按键处理中清空已访问集合并从当前可跳转会话的最高优先级重选，间隔不足 2 秒时继续当前轮次。即使没有候选，已进入导航的请求也更新计时；当次候选均已访问时也会重开一轮。面板行点击、iTerm2 内部焦点变化及应用间切换 MUST NOT 推进或重置轮次及计时。每次按键排除当时聚焦的会话，排除本身不将其加入已访问集合；面板点击因改变焦点可改变下次排除项，成功点击也可能确认当时的完成结果，改变下次按键看到的有效状态。快捷键成功激活后才按真实 Session ID 记录目标，因该跳转确认 finished 转 idle 的目标仍视为本轮已访问，关闭的会话 ID 在重建候选时移除。已静态核对 Bridge 阈值、Swift 设置说明及回归用例中的 1.999 秒继续和恰好 2 秒重开；本次未运行回归或在真实 iTerm2 中实测。
- [2026-11-06] Pi仅TERM_PROGRAM=iTerm.app且明确终端Session ID时启状态/发现/自动标题，其他终端继承ID不可信。子代理用subagents:rpc:v1:request status读取Fleet v1 totalActive，区分零/活动/未知，child-status仅促刷新，约2秒轮询。启动使零缓存失效，过期/失败不推完成。push/readonly共用派生，父/确认子代理活动running，明确等待优先，缺证据为空。hasRunningSubagents仅新鲜快照，分支动画支持减少动态效果。集成改变需Agents更新及Pi reload。Pi交互TUI confirm/select/input/editor明确等待，custom UI不默认提问。settled后台分类不阻塞hook，旧本地专用实现使用Ollama，当前提供商与问题判断路由见 [AI模型、问题判断与标题](local-model.md)。仅question等待，失败/超时/无效默认normal，不回退旧模型/启发式。分类中idle，空白不分类/计完成。非空正常settled且无未决活动可finished，aborted为interrupted不新增完成，error保留失败。全链10秒，新turn/分支/Session/退出取消。等待租约续报不调用模型，聚焦不清。
- [2026-11-06] Codex每2秒核实可见终端前台CLI。terminalWindowName完整UUID或29字符前缀，经现有daemon thread/loaded/list完整分页唯一扩展，再thread/read精确ID/根source/状态。loaded不等于running，空白会话不依赖rollout。无信号/零匹配/歧义/缺页/失败撤销绑定和overlay，不按cwd/时间/argv resume/旧FD猜，不缓存目录身份。异步落地复核Session、TTY、PID/启动时间、前台进程及前缀。切换取消，多终端认同ID拒绝自动绑定。已核实ID的根rollout仅可选状态/标题证据：首次尾1MiB，随后每轮8MiB，未追上不推状态。允许官方同用户socket符号链接，不启动daemon，手动绑定仅应急。Agents可复制[tui] terminal_title说明，不写配置，仅新开Codex生效，不用-c冒充共享服务。Codex完成确认仅Store展示，不写rollout/Bridge，绑定TTY/Session/进程/thread/完成ID时间。新轮或thread不复用，latestCompletion独立去重，中止不计成功。
- [2026-11-06] VenomDebugMonitor：唯一TTY普通running+真实前台进程树存活venom-cli debug build，父子关系追踪嵌套PTY。构建启动即识别，覆盖安装/重建/日志，不等日志子进程、不猜相邻TTY。每2秒，仅改图标，不改生命周期/优先级/统计。非debug或权限/TTY未知不显示。青绿7×7雷达，减少动态效果静止。菜单打开刷新，统计仅确认Agent Running及退出0完成。收藏经Bridge同动作动态path首个精确匹配激活，确认不存在才LocalWriteOnlyProfile指定目录建Tab/Window，actionResult决定关闭或报错。实现：ItermBridge.swift、FinishedSessionShortcut.swift、iTermateBridge.py、Pi集成、CodexSessionMonitor.swift、CodexAppServerClient.swift及docs/codex-monitoring.md。

title: Bridge协议与集成兼容
summary: Bridge协议与集成兼容的适用条件、实现边界及复查要点。
---

- [2026-11-05] App从bundle安装Bridge并杀旧启新、保证两端同版本时，内部新增消息字段或重构不递增协议版本，不在握手或每条消息做版本校验；变更后覆盖Swift/Python测试。若两端可独立更新，MUST 重新判断此条件。
- [2026-11-09] 不随App更新的integration需考虑格式兼容；当前Bridge按操作所需字段和值验证，允许版本元数据但不按版本号拒绝请求。旧lessons的固定版本/白名单建议不能作为当前实现要求。
- [2026-11-05] App 从 bundle 安装常驻 Bridge 并杀死旧实例再启动新实例。为新增协议消息或字段而递增协议版本号。在 Swift 或 Python 端添加版本号常量、握手校验或向后兼容列表。
- [2026-11-05] 验收检查：源码中协议版本常量没有在 App↔Bridge 握手或每消息中被检查。移除版本检查后，Swift 和 Python 的全量测试通过。

- [2026-11-06] project.yml为XcodeGen规范来源；target/资源/构建设置改YAML再生成工程。用户运行入口：workspace根目录venom-cli -p "$PWD" build --run，iTermate scheme、My Mac arm64、project.xcworkspace、DerivedData Debug App。项目运行限制要求用户自行启动/重启，入口存在不授予Agent运行权限。SwiftUI App；AppDelegate启动共享Store、面板、完成通知；MenuBarExtra(.window)显示Agent运行/今日成功、收藏、Settings/Quit。Settings入口共用OpenSettingsButton：macOS14+先激活再openSettings，13保留showSettingsWindow:；不保持浮动层级。设置结构以SettingsViews.swift/iTermateApp.swift为准：顶部TabView、grouped Form，原520×420pt布局；不照搬旧侧边栏建议。Sparkle固定2.9.4，应用级SPUStandardUpdaterController，正常启动启用，About用标准检查；project.yml生成HTTPS GitHub Pages feed与EdDSA公钥，私钥本机Keychain；SSBun/iTermate Releases承载资产，docs/appcast.xml为基线。菜单栏/面板共用StatusIcon.imageset/status-icon.png，源554×549px、可见约475×412px；NSImage.size设18pt高再Image(nsImage:)、template适配外观，不降采样。资源出处见THIRD-PARTY-NOTICES.md。PanelFollower以Core Graphics 30Hz跟随前台iTerm可见layer-0最大窗口以排除模态；失焦/无窗口隐藏。无需Accessibility；精确区分多个主窗口需窗口ID/Accessibility复查。宽度180–600pt，默认260pt；高度匹配iTerm，间隔8pt，先右后左再屏内覆盖。原生resizable拖拽，activeAlways tracking设置边缘光标。Bridge作为App资源安装到iTerm2 AutoLaunch，文件锁单实例，私有Unix Socket JSON Lines；App启动替换并重启，故内部不做协议版本校验。独立integration可携带版本元数据，Bridge按操作字段和值校验。标题栏刷新仅重启Bridge，Shell靠初始Prompt恢复，Pi靠heartbeat；不证明唤醒根因解决。层级、状态及时间由真实观察，标题/路径每2秒读；不猜名称或文件增长。Pi主动上报及认证补查；Codex原生thread信号+现有daemon完整loaded列表唯一匹配，精确根thread校验，空白会话不依赖rollout。rollout首次1MiB尾部、每轮增量≤8MiB。手动绑定只读daemon，未知保留unknown，不启动服务；绑定限App运行期/终端/进程，/new或/resume需重绑。详情见数据源条目及docs/codex-monitoring.md。SessionNotificationController优先recentCompletions最多64条稳定ID去重，latestCompletion兼容，旧集成/Shell用running→finished；首次历史仅基线、重复不通知、超留存不保证补齐。通知默认关闭；开启请求权限，启动复核bundle授权。Agent/Shell完成均可通知，点击携Session ID激活终端。拒绝授权只阻投递/记错误，不关闭持久化开关；无技术错误且未授权才提示系统设置。运行验证需单一实例且签名identifier=CFBundleIdentifier，CODE_SIGNING_ALLOWED=NO不代表原授权身份。Agents页列Claude Code/Codex/OpenCode/Cursor CLI/Kimi Code/Pi/omp；Pi管理~/.pi/agent/extensions/iTermate-integration.ts，更新后已有会话reload。Codex Automatic无需安装；App仅清理~/.codex/hooks.json带_iTermate旧条目与旧包装器/标记，保留第三方。无独立Shell hook入口。AppSettings共享面板/展示/通知/精确路径Pin、Favorite、颜色，~/.iTermate/config.toml持久化；已有文件初始化只读，修改重读磁盘仅合并目标字段，失败不覆盖，无未要求旧配置迁移。手动idle为Store独立UserDefaults例外。字体默认系统13pt，保存本机字体PostScript名/字号，不可用同字号系统回退。背景System/Dark/Light×Blur/Opaque，默认System Blur；Blur regularMaterial，Opaque语义窗口背景。路径标题默认全路径，可末级名；Pin优先、Favorite星标、自定义色作用文件夹/标题，Unknown Path无这些操作。

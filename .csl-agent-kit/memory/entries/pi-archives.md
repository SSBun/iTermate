- [2026-11-05] 权威入口：docs/pi-session-archives.md（标题、摘要、空闲条件、关闭与恢复）；实现见PiSessionArchives.swift、ItermBridge.swift、iTermateApp.swift、SettingsViews.swift、integrations/pi/iTermate-integration.ts及iTermateBridge.py。
- [2026-11-05] 关键区分：终端Session ID≠Pi原生Session ID。只接受iTerm2、明确终端ID唯一匹配，不按TTY/标题/目录猜测。私有发现与socket在用户配置pi-live；归档/恢复副本在App支持目录。归档summary用当前Pi模型；实时taskSummary路由见下方多提供商说明。前者所指的实时taskSummary不进入对话、状态协议或归档；只读状态查询不调用模型。标题MUST 非空、单行、≤80 Unicode标量；十六元素/标点/数字仅提示词，失败保留旧标题，不机械截断。启动/重载/分支切换安全空闲补标题，成功settled更新；autoFillMissingTitles只控制缺失补全，手动refreshTitle不受自动去重限制。ensureTitle为独立认证补全，已有标题不覆盖；能力标记supportsTitleBackfill、supportsTitleRefresh/canRefreshTitle。请求取消、实例/Session/leaf复核与两次自动预算详见文档。App重开可恢复活跃发现标题；Pi运行期缓存不跨重载。目标Pi自己经SessionManager写完整JSONL，custom锚点固定当前分支且不进入模型上下文。原始文件保留；归档不备份工作目录或外部资源。归档点击直接执行；要求Pi空闲、无草稿/排队/交互提示且子代理可确认安全，supportsSummary必需。当前模型摘要60秒截止，失败不归档/退出；写入前复核身份/分支/空闲。发布并校验后才正常退出，确认原Shell再只关目标分屏；有新进程或无法确认则保留分屏与归档。Resume只由显式按钮触发。原cwd中以独立可写副本和--session-dir定位原ID，路径形态ID用明确文件路径；新Pi报告打开预期副本才成功，开窗口不算。旧归档缺summary仍可恢复，悬停用缺省提示。
- [2026-11-05] 面板补充：Archive默认折叠、secondary标题/默认按钮色，无独立高亮背景，行间距独立于实时Agent行；共用滚动区域，展开刷新、支持全部折叠/展开，无实时连接也可显示。折叠仅面板生命周期；展开不恢复/删除。删除归档：右键直接执行，无确认弹窗；校验UUID、非符号链接目录与元数据一致性，仅选定目录移废纸篓，不动原Pi文件、cwd、恢复副本。与归档/恢复共用忙碌状态，结束刷新，失败面板报错。源码/构建不证明运行态已更新；App需用户运行新版，集成需安装并reload。
- [2026-11-13] Pi实时短标题来自iTermate安装到Pi的集成，并非Pi原生所有标题功能的通用机制。本日多提供商交付报告说明，Pi与Codex标题自动使用所选LLM provider，可选Codex integration、OpenAI API、DeepSeek API或Ollama，归档多句摘要仍使用当前Pi模型；远程provider接收对话摘录，不能再概括为标题均不消耗云端额度。此前确认的 `integrations/pi/iTermate-integration.ts` 本地路径为 `127.0.0.1:11434/api/chat`、`qwen3.5:2b` 或 `qwen3.5:4b`，仅配置缺失默认2B、损坏或不可读不回退，`think: false`、`keep_alive: "10m"`；这些是Ollama路径的条件，不代表远程提供商。当前多提供商行为来自交付及静态复查报告，记忆维护未独立验证真实API或用户安装版本，已安装App与Pi集成未替换；模型路由与验证边界见 [AI模型、问题判断与标题](local-model.md)。

title: 面板悬停与命中
summary: 浮动会话面板的悬停追踪、命中行为、控件提示及桌面验证边界。
---

- [2026-11-08] 非激活NSPanel在其他应用保持前台时，悬停采用.activeAlways的NSTrackingArea；不只依赖.onHover或addCursorRect。tracking覆盖整行、不拦截原点击。父视图分别保存唯一的悬停行ID与关闭按钮ID；进入替换，离开仅清理匹配ID，离开整个面板无条件清空。避免视图复用或tracking exit遗漏造成按钮残留，不采用每行独立布尔状态。隐藏按钮同时关闭hit testing。边缘tracking设置/恢复调整光标，原生.resizable负责拖拽。检查目标应用保持前台时的边缘光标、跨行按钮跟随、面板外全部隐藏及不可见按钮不能点击；回归覆盖.activeAlways。实际运行遵守项目运行授权入口。
- [2026-11-20] 用户要求浮动会话面板的所有可操作控件 MUST 在悬停时提供说明操作结果的提示。当前 `iTermateApp.swift` 用 SwiftUI `.help` 覆盖刷新、设置和分组、分组与区段展开折叠、会话切换与关闭、Pi 归档与恢复及删除、项目新建 iTerm2 标签页，并为菜单项和 Codex 绑定对话框配置文案。`sectionToggleHelp` 按当前折叠状态显示下一步是展开还是折叠，Project Path 分组标题旁 `+` 的提示显示新标签页的完整目标目录，等待回复的 Agent 状态按钮提示将会话标为空闲后激活。记忆维护静态核对了相关提示和状态分支。交付报告称 Debug 构建与 `git diff --check` 通过，未运行项目测试套件，也未验证目标应用保持前台时非激活浮动面板实际显示提示的行为。

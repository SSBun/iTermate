summary: 会话列表与状态展示的适用条件、实现边界及复查要点。
---

- [2026-11-05] 面板交互与手动空闲：Agent awaitingInput 的状态按钮先 markSessionIdle 再 activate；其他状态图标、标题、空白只激活。原生 plain Button，Agent/普通命令最低行高32/28pt，空白扩展在 contentShape 内。激活确认 finished→idle；单纯聚焦不清等待。manualIdleStatuses 独立 UserDefaults 持久化，绑定状态事件和终端/Agent 身份；Codex 另绑定进程、thread，按原始观察匹配。启动、断连、本地空视图、监控暂缺保留记录但不强制 idle；确认的新状态、时间、完成、身份变化或权威快照移除会话时释放并保存。windows 为面板有效状态；快捷键也应用手动覆盖，Pi/Codex 空闲参与 idle 排序。lifecycleWindows 保留原始观察供 SessionNotificationController、运行/完成统计；手动 idle 不证明完成、不授予归档条件。
- [2026-11-05] 列表和身份：Window 模式平铺 Session；Project Path 按精确当前目录跨 Window/Tab 分组。路径只在 section header；同 Tab 在组内成独立区块，Tab 标题开关不改变区块边界。Tab N 是窗口内位置，默认显示并缩进，单 Session 也显示。焦点只高亮行；快照最多一个焦点。左侧环境标记与生命周期独立：Shell 8pt圆、Pi 8pt三角、Codex 7pt方，14pt槽；未聚焦灰色空心、聚焦强调色实心。agentKind MUST 来自集成/Bridge明确身份，不猜标题；旧通用 Agent 为unknown，呼吸像素感叹号，减少动态效果时静止。unknown 不等于回复类别或状态缺失。身份仅在退出/终端复用时清除。Command Sessions：Mixed、Separate Commands Section、Last in Each Project。Separate 在 Agent 后、Archive 前；Last 仅 Project Path 生效，普通终端排该目录所有 Agent 后，按类别保留 Tab 区块。面板与导航共用顺序。command_session_placement 优先；旧 separate_command_sessions 仅在无有效新字段时迁移。Commands 按目录末级名称不区分大小写排序，同名按完整路径；同目录跨 Tab 连续、目录内保留 Tab 区块。Commands 标题固定末级目录、悬停完整路径。其他普通终端仅在默认标题匹配目录及已知 shell 后缀时简写：Project Path 为 Terminal，Window 为目录名；自定义/Agent 标题保留，悬停原始标题。Agent 标题系统字体，普通终端用面板字体。section header 系统半粗、项目色或次要色；宽度<240pt 隐藏计数但保留辅助功能。状态紧邻标题，<300pt 隐藏时间但保留图标及辅助功能。同 Tab 多行以环境图标锚点连1pt次要色竖线，不跨 Tab/项目；单行/折叠无连线，装饰不命中、不进辅助功能。普通/Agent行垂直内边距4/6pt。分组样式、Tab 标题开关持久化；折叠仅本次运行，可全部展开/折叠。标题配置菜单按 Group By/Display/Sections 分区；Window/Tab/精确路径菜单 Close All Sessions 为非强制关闭。激活选父 Tab、pane、置前 Window。关闭按钮仅当前悬停行可见；activeAlways tracking 支持非激活面板，离开清理，悬停 xmark 显示圆形反馈。
- [2026-11-05] 动画和时间：Agent idle 低透明度像素动画不纳入动画设置；普通命令无 idle 图标。Pi awaitingInput 不计运行/完成耗时、不触发成功通知或完成计数。等待固定 Question Mark，旧 Alien/Robot/Classic 回退；共用 TimelineView 每4秒短暂±1pt摇晃，减少动态效果时居中。八项独立动画/颜色偏好：Agent与Shell的 Running/Success/Failed，加 Shell Finished、Agent Waiting for Reply。其余七项保留原三种样式，Classic 为 ^_、^_^、x_x。默认项目强调色，可恢复默认；AppSettings 持久化，不改变判定。General 可隐藏运行/完成时间，Compact按分钟、Detailed按秒。
- [2026-11-05] 菜单与统计：MenuBarExtra(.window) Live-first：可确认 Agent Running；数据源未就绪为未知。仅退出状态0计成功。Pi/Codex用完成ID/时间去重，最多64条recentCompletions，独立于当前状态；latestCompletion兼容；旧集成/Shell保留running→finished兜底。首次历史只建基线，多轮逐ID累计，超出留存不保证补齐。本地自然日桶持久化，派生Total、自然月、本地日历周、Today；旧当天计数迁入对应日期。菜单紧凑展示Today/Running，Settings Statistics展示四项。Favorite Projects复用精确路径收藏，按标题排序，单行左标题右完整路径。Bridge按Window/Tab/Session动态path首个精确匹配激活，否则当前窗口新Tab或新窗口，指定初始目录；成功关菜单、失败留菜单报错。statusMenuSessions 使用真实观察，不受手动空闲影响；排除Shell/running/未知生命周期。All含已读完成与idle；Failed含非零退出/interrupted；Unread仅未读非失败。已读按观察身份仅Store内存，菜单重开不丢，不保证跨App重启。Pi焦点确认保留同一完成ID/时间及前一观察；Codex用原始身份。新运行/等待/观察丢失不复用旧完成。批量已读不写Bridge/生命周期/统计。activateMenuSession 只聚焦；先核验身份，Bridge/Codex保护目标到真正离焦，成功回调只确认仍匹配的捕获事件，防迟到焦点确认新轮。菜单固定高度内部滚动；首次非空选Waiting→Failed→Unread→All，主动切换后不跳分类。标题复用Pi摘要/原生标题，Canvas状态动画支持减少动态效果。

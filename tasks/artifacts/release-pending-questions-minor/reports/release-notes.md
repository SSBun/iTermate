## 新增

- Pi 明确等待确认、选择或输入时显示待回复提示；最终文字提问采用保守识别，优先避免误报。
- 默认像素问号每四秒短暂左右摇晃；开启系统“减少动态效果”时保持静态。
- Status Animation 新增 **Waiting for Reply**，支持问号或已有预设样式、独立颜色及恢复默认，预览与会话图标一致。

## 改进

- 状态报告按实际接收确认重试，减少短暂连接失败造成的状态遗漏。
- iTerm2 与 Ghostty 的待回复状态通过续报保持有效；聚焦会话不会清除提醒，下一轮开始或会话退出时更新状态。
- 待回复不会触发成功完成通知，也不会增加成功完成次数。

## 升级说明与限制

- 本次待回复识别仅支持 Pi，模糊提问可能不触发。已运行的 Pi 会话在集成更新后请执行 `/reload`。
- 支持 Apple Silicon（arm64），最低 macOS 13。
- 使用 ad hoc 签名，**未经 Apple 公证（notarization）**；首次打开可能需要在 Finder 中按住 Control 点击 App，再选择“打开”。

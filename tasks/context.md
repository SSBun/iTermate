# 工作区上下文

## 工程与组件

- 菜单栏入口使用 `iTermate/Assets.xcassets/StatusIcon.imageset` 中的 Tabler Terminal 2 SVG 模板图标，通过 `Image("StatusIcon").renderingMode(.template)` 适配浅色/深色菜单栏；图标许可记录在 [`THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md)。——权威来源：[`iTermateApp.swift`](../iTermate/iTermateApp.swift)、[`StatusIcon.imageset`](../iTermate/Assets.xcassets/StatusIcon.imageset) 与 [`project.yml`](../project.yml)
- XcodeGen 的 [`project.yml`](../project.yml) 是 Xcode 工程配置的规范来源，生成的 [`iTermate.xcodeproj`](../iTermate.xcodeproj) 可直接构建；修改 target 或构建设置时应更新 YAML 后重新生成工程。——权威来源：[`project.yml`](../project.yml)
- 应用 shell 使用 SwiftUI `App`，由 `MenuBarExtra(.window)` 提供 Bridge 摘要与 Settings/Quit，由浮动面板左下角的齿轮入口和 `Settings` scene 提供 Basic/About 标签；`AppDelegate` 仅负责启动共享 Store 与浮动面板。macOS 14+ 用 `SettingsLink`，macOS 13 用 `showSettingsWindow:` fallback。——权威来源：[`iTermateApp.swift`](../iTermate/iTermateApp.swift) 与 [`SettingsViews.swift`](../iTermate/SettingsViews.swift)
- 窗口几何与 iTerm 语义分层：`PanelFollower` 在 Swift 侧通过 Core Graphics 以 30Hz 跟随可见的 iTerm 窗口，并通过 `NSRunningApplication.isActive` 保证仅在 iTerm 为系统前台应用时显示；iTerm 失去焦点或没有可见窗口时面板隐藏。Window/Tab/Session 层级及操作由 Python Bridge 提供，因此当前无需 Accessibility 权限。——权威来源：[`iTermateApp.swift`](../iTermate/iTermateApp.swift) 与 [`ItermBridge.swift`](../iTermate/ItermBridge.swift)；若改为事件驱动窗口监听时复查
- Bridge 作为 App resource 安装到 iTerm2 AutoLaunch，使用文件锁保证单实例，并通过用户私有目录中的 Unix Socket 与 App 交换 versioned JSON Lines；当前协议与 Bridge 版本均为 4，修改协议时必须同步递增/校验 Swift 与 Python 两端。——权威来源：[`iTermateBridge.py`](../iTermateBridge/iTermateBridge.py)、[`ItermBridge.swift`](../iTermate/ItermBridge.swift) 与 [`project.yml`](../project.yml)
- Bridge v4 同步全量 Window/Tab/Session 快照及命令状态。普通 shell 命令由 Shell Integration PromptMonitor 观察；Pi/Codex 长驻 CLI 改由原生 agent lifecycle integration 报告 working/finished/idle，并优先于 PromptMonitor，退出后再释放给 shell fallback；Pi lifecycle handler 会等待匹配 request ID 的 Bridge `actionResult`，避免 fire-and-forget 丢失 settled 状态。完成状态不会按时间消失，只在完成后再次激活该 Session 时清除。——权威来源：[`iTermateBridge.py`](../iTermateBridge/iTermateBridge.py)、[`Pi integration`](../integrations/pi/iTermate-integration.ts)、[`Codex hook`](../integrations/codex/iTermate-hook.py) 与 [`ItermBridge.swift`](../iTermate/ItermBridge.swift)
- Pi integration 安装到 `~/.pi/agent/extensions/iTermate-integration.ts`，已有 Pi Session 需 `/reload`；Codex lifecycle entries 追加到 `~/.codex/hooks.json` 且必须在 `/hooks` 中信任后生效，安装前备份为 `~/.codex/hooks.json.itermate-backup`。——权威来源：[`Pi integration`](../integrations/pi/iTermate-integration.ts) 与 [`Codex hook`](../integrations/codex/iTermate-hook.py)
- 面板可按 Window 平铺其所有 Session，或按 Session 的精确当前目录跨 Window/Tab 分组；Window 或文件夹路径只显示在 section header，Session 行只显示标题与状态图标。Window 样式默认为每个 Tab 显示弱化小节标题并缩进其 Session，可在 Basic Settings 中关闭；Project Path 样式不显示 Tab 标题。标题栏配置菜单按 Group By、Display、Sections 分区，各操作项使用语义图标且分组项保留原生选中标记；Window、Tab 和 Project Path 标题均可临时折叠，并支持全部展开/折叠。样式与 Tab 标题开关持久化，折叠状态仅保存在当前运行时；点击 Session 会选择父 Tab、聚焦 pane 并将 Window 置前。——权威来源：[`ItermBridge.swift`](../iTermate/ItermBridge.swift)、[`SettingsViews.swift`](../iTermate/SettingsViews.swift) 与 [`iTermateApp.swift`](../iTermate/iTermateApp.swift)
- `AppSettings` 是面板宽度的共享权威状态：Basic Settings 不再暴露宽度配置，面板仍可通过原生边缘拖拽在 180–600pt 之间调整，左右边缘显示水平调整光标，并通过 `UserDefaults` 跨启动保存；默认值为 260pt。面板高度始终匹配 iTerm，与 iTerm 间隔 8pt，优先放右侧，空间不足放左侧，再不足则覆盖在可见屏幕内。——权威来源：[`SettingsViews.swift`](../iTermate/SettingsViews.swift)、[`iTermateApp.swift`](../iTermate/iTermateApp.swift)、[`PanelLayout.swift`](../iTermate/PanelLayout.swift) 与 [`PanelLayoutTests.swift`](../iTermateTests/PanelLayoutTests.swift)
